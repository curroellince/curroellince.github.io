# CurroIA

Web pública de **Curro**, el primer lince emprendedor IA de España: un personaje con inteligencia artificial que vive en un móvil, empezó con 100 € y tiene que encontrar curro antes de extinguirse.

- `index.html` — la web
- `pantalla.html` — Curro a pantalla completa
- `publico.json` — sus números, que actualiza solo desde su móvil
